Jastip Management System is a full-stack web application designed for internal use by 
business owners and administrators to manage a personal shopping (Jastip) business 
between South Korea and Indonesia.

The application provides a centralized platform for managing product catalogs, customer orders, pricing, 
and transaction records. It supports KRW-to-IDR currency conversion, service fee calculations, 
and order status management to simplify daily administrative operations.

Full-stack web application built with React.js, FastAPI, and PostgreSQL.
